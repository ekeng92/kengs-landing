Keng Family Brain - Privacy Policy

Effective November 1, 2026.

Keng Family Brain is a private, single-user tool built and used by Eric Keng to keep notes about his own family and household. It is not offered to the public. The only person who signs in to it is its owner.

What it accesses

With the owner's permission it reads, and never changes, Gmail messages that the owner has labeled for it, using the read-only scope https://www.googleapis.com/auth/gmail.readonly. It cannot send, delete, or modify mail. It also reads documents from the owner's own Google Drive folder on his computer.

How the data is used

Text from the labeled messages is stored only on the owner's computer. After removing obvious secrets such as card, account, and Social Security numbers, a short portion is sent to an AI model service (GitHub Copilot) solely to write summary notes for the owner. Those notes are kept in the owner's private repository. The data is used only to provide this feature for the owner. It is not used for advertising, is not sold, and is not shared with anyone else.

Storage and retention

Access tokens are kept in the owner's macOS Keychain. Message text stays on the owner's computer and is deleted on request by the owner at any time.

Your choices

The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
